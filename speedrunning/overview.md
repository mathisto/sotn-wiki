# SOTN Speedrunning Guide

> Source: [sotn.fun/wiki](https://www.sotn.fun/wiki/Speedrunning)

Speedrunning is the act of choosing a game and a set of rules, and attempting to complete that game as fast as possible while abiding by the rules.

---

## Techniques

### Movement Techniques

| Technique | Description |
|-----------|-------------|
| **Book Jump** | Uses library books for height |
| **Infinite Wing Smash** | Sustained Wing Smash movement |
| **Shield Dash** | Fast horizontal movement with shield |
| **Double Jump Reset** | Resets double jump availability |
| **Frontslide** | Fast sliding movement |

### Minor Glitches

Permitted in all categories:
- Holy Water damage stacking
- MP Refill glitch

### Save Corruption (ACE)

Arbitrary Code Execution via save corruption. **Only allowed in Alucard Any% ACE category.**

## Routes

*Note: The sotn.fun wiki does not currently have detailed route documentation. Routes are category-specific and evolve with new discoveries. Check [speedrun.com/sotn](https://www.speedrun.com/sotn) for current route guides and video tutorials.*

**General routing principles:**
- Main categories route through required progression triggers
- Glitchless routes follow intended game progression
- ACE routes aim for fastest code execution setup
