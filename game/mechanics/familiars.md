# Familiars

Familiars are companion entities in Castlevania: Symphony of the Night that assist Alucard during gameplay.

## Familiar List

| ID | Name | Notes |
|----|------|-------|
| TT_000 | Bat | — |
| TT_001 | Ghost | — |
| TT_002 | Faerie | — |
| TT_003 | Demon | — |
| TT_004 | Sword | — |
| TT_005 | Yousei | JP Only |
| TT_006 | Nose Demon | JP Only |

## Notes

- **Yousei** and **Nose Demon** are exclusive to the Japanese version
- Each familiar has its own overlay file in the decomp project (`tt_000` through `tt_006`)
- Familiars level up independently based on usage
