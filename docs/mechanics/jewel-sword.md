# Jewel Sword

When you kill an enemy with the Jewel Sword, there is a chance for the Jewel Sword to spawn a random Gem. If a Gem is spawned, the ratio of which Gems will spawn is as follows:

## Gem drop ratios

| Gem | Ratio |
|-----|-------|
| Zircon | 3073 |
| Aquamarine | 768 |
| Turquoise | 208 |
| Onyx | 32 |
| Garnet | 8 |
| Opal | 5 |
| Diamond | 2 |
