# Forbidden Library

**Japanese Name:** 禁書保管庫 (*Kinsho Hokanko*)  
**Game:** Castlevania: Symphony of the Night  
**Music:** Lost Painting

## Location Details

The Forbidden Library is an upside down version of the Long Library in the Reverse Castle. A blue, dreamy atmosphere cascades over every room, giving this area a melancholy appeal.

**Access:** Only accessible from the Reverse Outer Wall (to the left)

**No bosses** in this area.
